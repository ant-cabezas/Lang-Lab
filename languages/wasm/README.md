# languages/wasm: the WebAssembly side study

WebAssembly is **not a matrix entry**: nothing here is in `languages.json`, `versions.lock.json`, the matrix,
the README leaderboard, and CI only runs a smoke check of the harness (`scripts/wasm-smoke.sh`). Everything belongs to the side study described in
[`docs/wasm-study.md`](../../docs/wasm-study.md), driven by
[`scripts/wasm-study.sh`](../../scripts/wasm-study.sh). Results go to `results/wasm/`; the tables in the study
page are generated by [`scripts/make_wasm_tables.py`](../../scripts/make_wasm_tables.py).

Every ratio is `wasm differential / native differential` for the same language and source: **lower is better**,
1.00 = no overhead over native. It is never a cross-language ranking.

## Layout

| Path | What it is |
|---|---|
| `Dockerfile.base` | `lang-lab-wasm-base`: `gcc:14` plus wasi-sdk 34, the official LLVM 23.1.0 release (native control for C-based runtimes), wasmtime 50.0.0, Node 26.5.0 and the qemu `insn` backend. Every download is sha256-pinned. |
| `run-node.mjs` | Runs a WASI preview 1 module on Node's V8 (`node:wasi`), with the same view of argv, environment (`--env NAME=VALUE`) and `/app` that `wasmtime run --dir /app::/app` gives; `random_get` returns a fixed byte stream (`--random-os` for OS randomness). |
| `<lang>/Dockerfile` | One lane per language, `FROM lang-lab-wasm-base`, tagged `lang-lab-wasm:<lang>`: the wasm build of every benchmark and, where the matrix image cannot be the control, a native build from the same source and compiler. |
| `<lang>/lane.json` | The lane's columns (native, wasmtime, V8, any reference columns), run templates, environment, versions, every source transform, every known asymmetry and every n/a cell with its reason. Includes **`columnRoles`** (`control`, `wasm`, `reference`, `check`) for table generation. Read by the driver and copied into each envelope. |
| `c/lp64.sh` | Build-time transform for the C sources (wasm32 is ILP32; 13 of 18 sources are wrong on it unchanged). |
| `swift/int64.sh`, `swift/int64-shim.swift` | Build-time shim making Swift's `Int` 64-bit on wasm32, applied to the 11 benchmarks that need it. |
| `php/patches/`, `php/compat/` | The WASI patches PHP 8.4.8 needs (from gophper-wasm, MIT, licence included) and the stubs for the POSIX calls WASI lacks. |
| `csharp/` | The .NET `wasi-experimental` workload build (Mono interpreter), its preview 1 relink wrapper and the build-guard override. `vbnet/` reuses it. |
| `teavm/` | The TeaVM 0.13.1 build shared by the Java, Kotlin and Scala lanes (`jars.lock` pins every jar by sha256). |
| `not-measured.md` | The evidence for the four languages with no wasm column (OCaml, Perl, Fortran, Elixir): versions tried, errors, outputs. |
| `ruby/alloc.rb` | Diagnostic only: counts heap allocations per benchmark (the 32-bit `VALUE` effect). |
| `experiments/` | The study-level experiments (wasmtime and wasi-sdk version sweeps, V8 tiers, jitter, code-generation options, wall-clock, the binary-trees frame diagnosis) and `ingest.py`, which writes their `results/wasm/` envelopes. Each has a README. |

## Rules that keep the study honest

- The canonical benchmark sources are never edited. A change a target needs is a build-time transform, listed in
  `lane.json`, and measured natively too wherever it could change native cost.
- Same compiler version and optimisation level on both sides wherever the toolchain allows it; otherwise the
  asymmetry is listed.
- Every cell runs at the full spec sizes and passes the spec checksum gate at both, or it is n/a with the error.
- wasmtime cells run `wasmtime run -C cache=n --allow-precompiled` with `TOKIO_WORKER_THREADS=1`; V8 cells run
  `node --predictable --single-threaded --single-threaded-gc --no-liftoff` (TurboFan; without `--no-liftoff`
  V8 never leaves its baseline compiler). The study page explains both.
- `message-ring` and the `-par` sources are excluded: WASI preview 1 has no threads.

See [`docs/wasm-rigor.md`](../../docs/wasm-rigor.md) for primary vs reference ratios and
[`docs/wasm-fairness-audit.md`](../../docs/wasm-fairness-audit.md) for audited cells. Harness:
`SKIP_IF_OK=1` skips re-measuring passing RAW cells; `scripts/assemble_wasm_envelope.py` assembles envelopes;
`scripts/wasm-smoke.sh` runs a cheap C-lane smoke test.
